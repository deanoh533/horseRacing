# 🎨 KRA 경마 분석 앱 - UI/UX 디자인 v2.0

**디자인 컨셉:** 프로페셔널 다크모드 + 데이터 중심  
**타겟:** 경마 전문가  
**디바이스:** 반응형 (모바일 + 데스크탑)  
**핵심 가치:** 경주별 상세 분석 리포트

---

## 1️⃣ 디자인 철학

### 핵심 원칙
1. **분석 깊이 우선** - 정보 밀도가 높지만 체계적으로 정리
2. **데이터가 주인공** - 차트, 그래프, 표가 중심
3. **눈에 편한 다크모드** - 장시간 분석에 적합
4. **신속한 의사결정** - 핵심 정보 즉시 파악
5. **상세 리포트 가능** - PDF 출력 가능한 전문 분석

### 사용자 경험 시나리오
```
🎯 전문 분석가의 하루:
  06:00 - 모바일로 오늘 경주 일정 확인
  09:00 - 데스크탑으로 출전마 데이터 분석
  10:30 - 경주별 상세 리포트 생성
  12:00 - 현장에서 모바일로 최종 확인
  18:00 - 실제 결과 입력 → 학습 진화 확인
```

## 3️⃣ 정보 아키텍처 (Information Architecture)

### 📱 사이트맵

```
🏠 대시보드 (Command Center)
├── 📅 오늘의 경주 일정
├── 📊 학습 상태
└── 🎯 누적 적중률

🏁 예측 분석 (Main Feature)
├── 경주 선택
├── 출전마 분석 (사이드바)
└── 상세 분석 패널
    ├── 14개 항목 점수
    ├── 데이터 출처
    ├── 과거 이력
    └── 비교 분석

📋 상세 리포트
├── 경주 요약
├── 출전마별 분석
├── 예측 결과
└── PDF 다운로드

✅ 결과 입력
├── 경주 후 착순 입력
├── 예측 vs 실제 비교
└── 학습 데이터 누적

📈 통계 & 인사이트
├── 상관계수 분석
├── 가중치 진화
├── 적중률 추이
└── 리포트 아카이브

⚙️ 설정
├── KRA API 키
├── 알림 설정
└── 데이터 관리
```

- 카드: 살짝 작아짐 + 글로우
- 점수 카드: 회전 효과 (3D)

- 분석 중: 진행률 + 단계별 텍스트
- 백테스트: 6단계 진행 시각화

**4. 트랜지션**
- 페이지 전환: 부드러운 페이드 (200ms)
- 모달: 슬라이드 업 + 페이드
- 차트: 데이터 변화 시 부드러운 애니메이션 (500ms)

## 6️⃣ 반응형 브레이크포인트

```css
/* 모바일 우선 디자인 */
@media (min-width: 640px)  { /* sm: 태블릿 세로 */ }
@media (min-width: 768px)  { /* md: 태블릿 가로 */ }
@media (min-width: 1024px) { /* lg: 데스크탑 */ }
@media (min-width: 1280px) { /* xl: 큰 데스크탑 */ }
@media (min-width: 1536px) { /* 2xl: 와이드 */ }
```

### 모바일 (< 768px)
- 하단 탭 네비게이션
- 단일 컬럼 레이아웃
- 압축된 카드 디자인
- 스와이프 제스처 지원

### 태블릿 (768-1024px)
- 상단 네비게이션
- 2컬럼 레이아웃
- 적당한 정보 밀도

### 데스크탑 (≥1024px)
- 사이드바 네비게이션 (선택)
- 3컬럼 분석 레이아웃
- 높은 정보 밀도
- 키보드 단축키
