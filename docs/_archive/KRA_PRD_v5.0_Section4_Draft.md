"이 말이 지금 시점에 얼마나 좋은 컨디션인가" - 능력 자체와는 별개

- 단, 5경주가 안 되는 말은 있는 만큼 사용

### 신호 1: 마체중 변화 🤔

**판단 기준 (가설):**
```
+5kg 이상: 비만 (감점) - 약간 우려
+1~+4kg: 양호 (만점 가능) - 컨디션 좋음
0kg: 일정 (중립)
-1~-3kg: 약간 감소 (양호) - 정상 변동
-4kg 이하: 급감 (감점) - 컨디션 우려
```

- ㄷ. 특정 거리/말 종류에 따라 기준이 다른가요?

### 신호 2: 착순 향상 추세 🤔

**판단 기준 (가설):**
```
완벽 향상: 5위→4위→3위→2위→1위 (점진적 상승)
강한 향상: 7위→3위→1위 (급격한 도약)
양호: 최근 3경주 평균 < 직전 3경주 평균
중립: 변화 없음
저하: 최근 3경주 평균 > 직전 3경주 평균
```

## ⭐ 4-3. 기수-말 궁합

### 정의
"이 기수와 이 말의 조합이 평소보다 더 잘 맞는가"

### 데이터 (확정)
- `hr_name` + `jk_no` 조합 이력
- 전체 기간 데이터

### 점수 계산 (PRD v4.0 그대로)
```
향상도 = 말의 전체 평균 착순 - 이 기수와 조합 평균 착순
신뢰도: 1회=0.5 / 2회=0.7 / 3회=0.85 / 4회=0.95 / 5회+=1.0
원점수 = 0.5 + (향상도 점수 - 0.5) × 신뢰도
```

**❓ 본인 노하우 확인 필요:**
- ㄱ. 위 공식이 본인 직관과 맞나요?
- ㄴ. 처음 조합인 경우 (이력 없음) 어떻게 처리?

## ⭐ 4-4. 기수의 최근 성적

### 정의
"기수가 최근에 좋은 컨디션/폼인가"

### 데이터 (확정)
- 최근 30일 (PRD v4.0과 동일)
- 서울+부산경남 통합

### 점수 계산 (🤔 가설)
```
착순 배점: 1착=3, 2착=2, 3착=1, 4착+=0
원점수 = 가중 점수 합계 / (출전 횟수 × 3)
```
