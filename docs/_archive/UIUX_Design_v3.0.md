# 🎨 KRA 경마 분석 도구 - UI/UX 디자인 v3.0

**디자인 컨셉:** 프로페셔널 다크모드 + 데이터 중심
**타겟:** 본인 1명 (5년차 경마 분석가)
**디바이스:** 반응형 (모바일 + 데스크탑)
**핵심 원칙:** 실제 데이터가 메인, 점수는 보조
**최종 업데이트:** 2026-05-22

---

## 📋 v2.0 → v3.0 핵심 변경

| 항목 | v2.0 | v3.0 |
|------|------|------|
| 항목 수 | 14개 (컨디션 묶음) | **17개 독립 항목** |
| 네비게이션 | 단계 불명확 | **3단계: 날짜 → 경주 → 말** |
| 화면 구성 | 점수 위주 | **실제 데이터 메인, 점수 보조** |
| 표시 방식 | 절대 점수 (17/20) | **백분율 (%)** |
| 강조 시스템 | 단순 ⭐ | **⭐ 핵심(자동) + 🤖 인사이트(수동)** |
| 결과 입력 | 별도 화면 | **자동 (메뉴 제거)** |
| 인사이트 | 모든 항목 | **사용자 선택 4개만** |

## 1️⃣ 디자인 철학

### 핵심 원칙
1. **실제 데이터가 메인** - 분석가는 raw 데이터를 신뢰
2. **점수는 보조** - 가중치 백분율로 가이드만 제공
3. **3단계 깊이 조절** - 일반 5분, 중요 경주 깊이 분석
4. **두 강조 시스템** - 가중치 자동(⭐) + 사용자 수동(🤖)
5. **모호한 표현 금지** - "적중률" 같은 단어 대신 구체적 수치

### 본인 워크플로우 시나리오
```
06:00 - 모바일로 오늘 경주 일정 + 1-3위 빠르게 확인
09:00 - 데스크탑에서 중요 경주 깊은 분석 (30분 → 5분)
12:00 - 현장에서 모바일로 최종 확인 + PDF 출력
다음날 - 적중 결과 자동 확인 (수동 입력 불필요)
```

## 3️⃣ 정보 아키텍처 (3단계 + 보조)

```
🏠 화면 1: 날짜별 대시보드
  └ 날짜 + 가중치 + 경주 목록 (1-3위 + 복병)
       ↓
🏁 화면 2: 경주 상세 (출전마 한눈에)
  └ 실제 데이터 메인 + 가중치 % 보조
       ↓
🐎 화면 3: 말 상세 정보
  └ 17개 항목 모두 (데이터 + AI 인사이트)

[보조 화면]
📊 화면 4: 통계 & 인사이트
  └ 적중률 / 가중치 변화 / 상관계수 / 리포트 아카이브

⚙️ 화면 5: 설정
  └ API / 인사이트 4개 선택 / 동기화 / 학습
```
