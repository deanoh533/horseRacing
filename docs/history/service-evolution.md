## 1. 한눈에 — 버전 타임라인

이 도구는 "경마 전문가·세미프로 1,000명을 위한 SaaS"(v3)에서 출발해, PM 프레임워크를 적용해 페르소나를 구체화했다가(v4), 실제 수요를 직시하며 "본인 1명을 위한 개인 분석 도구"(v5)로 핵심 방향을 전환했다. 이후 실제 사용 패턴(AI 예측 1위만 확인 → raw 정보를 직접 보고 싶음)을 반영해 검증 레이어(출마정보 비교 화면)를 추가한 v6.1이 현행이다. v3의 "대중 서비스" 기획은 완전히 폐기됐고, 개인 적중률 향상이라는 단일 성공 지표가 살아남았다.

## 2. PRD 버전별 변화

### v3.0 — 대중 서비스 원형 (2026-05-22)

경마 분석가·베팅 애호가를 대상으로 한 다중 사용자 SaaS. 14개 점수 항목(레이팅·최근착순·거리적합성·주로적응·부담중량·기수폼·조교사폼·경주간격·출발번호·나이×거리×성별·혈통·계절패턴·기수-말궁합·배당률)을 스피어만 상관계수로 학습해 0~100점 종합 점수를 산출. 기술 스택은 React + Node.js + PostgreSQL + Railway. AI 보정(Claude API)은 선택사항으로 정의.

### v4.0 — PM 프레임워크 적용 + 인프라 전환 (2026-05-22)

"KRA Analyzer Pro" 브랜드로 PM 관점 재정비. 박정수(35-45세 데이터기반 분석가)·김다영(28-35세 입문자) 가상 페르소나 구체화, 6개월 MAU 100명·1년 MAU 1,000명·유료 전환 5% 등 성장 지표 설정. 인프라를 Railway→Supabase로 전환해 비용 0에 가깝게 조정. PDF 리포트 기능 추가. 실질 기능 범위는 v3와 동일하나 PM 프레임워크(문제정의·JTBD·페르소나·성공지표) 체계화.

### v5.0 — 핵심 전환: 대중 서비스 → 개인 도구 (2026-05-22)

가장 중요한 방향 전환. 가상 페르소나·MAU·NPS·마케팅 전략을 전부 폐기하고, "사용자 = 본인 1명, 성공 지표 = 내 적중률 향상"으로 재정의. 이에 따라 가중치 학습 방식이 "완전 자동" → "하이브리드(본인 노하우 + 시스템 제안 + 본인 결정)"로, 결과 입력 방식이 "수동" → "API 자동"으로 변경. 4대 핵심 분석 영역(컨디션·거리적성·기수-말 궁합·기수 최근 성적)을 실제 5년 노하우 기반으로 재설계. 이 전환으로 SaaS 인프라·마케팅·다중사용자 인증이 모두 범위 밖으로 나갔다.

### v6.1 — 검증 레이어 추가: 출마정보 비교 화면 (2026-05-26)

실제 사용 패턴 관찰에서 촉발된 기능 확장. AI 예측 1위만 확인하고 18개 항목 점수는 거의 안 보는 패턴이 드러났고, raw 정보를 사용자 시각으로 직접 보고 싶다는 요구가 명확해졌다. 포지셔닝을 "AI가 예측하는 도구" → "AI가 예측하고 사용자가 검증할 수 있는 도구"로 재정의. 출마정보 4열 비교 화면(마정보·기수정보·직전경주·베팅조합)을 신설. 18개 항목 점수는 핵심 결과에서 보조 시그널로 역할 전환.

## 3. 지표셋 진화

v3.0에서 14개 항목으로 출발한 점수 체계는 v5.0에서 실사용 검증(컨디션 7신호 구체화, 거리적성 판단 기준 정밀화)을 거쳤고, 이후 구현 과정에서 21개로 확장됐다. 항목 추가·산식 변경은 게이트(probe:corr → backtest:box)를 통과한 것만 채택하는 방식으로 표준화됐다. 항목별 ρ·가중치·채택 상태 현황은 [score_roadmap](../score_roadmap.md) §1 마스터 상태표가 SSOT.

## 5. UI 변천

**UIUX v2.0:** 프로페셔널 다크모드(#0A0E27 딥 네이비 기반). 대중 분석가 워크플로우 가정 — 데스크탑 심층 분석 + 현장 모바일 확인 + PDF 출력. 14개 항목을 절대 점수(17/20)로 표시. 5단계 화면 구조(대시보드→경주분석→컨디션패널→가중치→AI인사이트→아카이브).

**UIUX v3.0:** 개인 도구 전환 반영. 14→17개 독립 항목. 화면 네비게이션을 "날짜→경주→말" 3단계 명시화. 표시 방식을 절대 점수→백분율(%)로 전환. "실제 데이터가 메인, 점수는 보조" 원칙 도입. ⭐ 핵심(가중치 자동) + 🤖 인사이트(사용자 선택 4개) 이중 강조 시스템. AI 인사이트 사용자가 경주당 4개만 선택.

**현행(v6.1 구현 후):** 모바일 2+2 그리드 / 데스크탑 4열(`grid-cols-2 md:[grid-template-columns:2fr_1.2fr_3fr_2fr]`). 아코디언 미사용. RaceInfoBlock 공통 헤더(3화면 공유). `/picks` 강추/주목 뷰 신설. Platt "우승 N%·연승 M%" 수치 표시. 다크모드 전제 유지, 개발 용어 제거 완료. 상세 현황 → [docs/status/06-ui](../status/06-ui.md).
