## ⭐ 30번 "절대능력지수" 추가 검토

이미지 설명:
> **30 절대능력지수:**  
> &nbsp;&nbsp;− 숫자가 높을수록 좋은상태  
> &nbsp;&nbsp;+ 숫자가 높을수록 나쁜상태

→ 음수 절댓값이 크면 좋고, 양수가 크면 나쁘다. 예시 값 "-15" = 음수 큰 값 = 좋은 상태.

**해석 후보:**
1. KRA `horseRating` 변동치 (이전 레이팅 - 이번 레이팅)
2. KRA `등급변동` API (#15058076) 데이터
3. 에이스경마 자체 산출 지수 (외부)

⮕ data.go.kr에서 "**한국마사회 경주마 등급변동 정보**" (#15058076) 확인하면 비슷한 데이터일 가능성. 추후 검토 항목.

## 권장 — RaceEntries 화면 매핑 (단계별)

### Phase 1 (즉시 가능, 현재 데이터로)

**기본 행 (한 줄에 보임):**
- ① 마번 / ② 마명 / ⑤ 성·나이 / ⑪ 기수 / ⑦ 총상금 / ⑥ 전적

**행 클릭 → 펼침 영역:**
- ③ 혈통 (horses join, sync 후)
- ⑧⑨⑩ 마주 정보 (derived)
- ⑫ 기수 통산 (jockey_stats join)
- ⑬⑯⑰ 최근 3개월/조 통계 (derived)
- ⑮ 출주간격 (derived)
- ⑲ 조교 바퀴수 (training_logs join, sync 후)

**사후 모드 (경기 결과 있을 때) 펼침 추가:**
- ⑳ 기록 / ㉓ 경주 / ㉔ 거리·날씨 / ㉕ 착차 / ㉖ 인기 / ㉛ 마체중 / ㉜ 배당
- ㉑㉒ 초/종 200m 통과순위 (코너 패턴 분석)
- ㉗㉘㉙ 구간 시간 (초반/G3F/후반)

### Phase 2 (데이터 확보 후)

- ㉚ **절대능력지수** ⭐ → 등급변동 API 신청·연동 후 표시
- ⑭ 조교상태 / ⑱ 마필가격 / ㉝ 복기평 — 외부 데이터 검토
- ㉞ 경주로 빠르기 수치 — KRA 경주로 상태 데이터 검토
