## 🎯 정의 / 의도 (이상)

**"부담중량을 짊어진 채로 거둔 성적 = 진짜 실력"**

### 도메인 통찰 (사용자 입력)

KRA 의 핸디캡 시스템:
- 잘하는 말에게 더 무거운 짐을 매김 (예: 1억+ 강자 = 58~60kg)
- 약한 말은 가볍게 (예: 미입상 = 52~53kg)

→ 단순히 "지금 부담 가벼움 유리" 가 아니라, **"무거운 부담 짊어진 채로도 좋은 성적 → 진짜 강자"** 가 정답.

> "잘하는 말이 부담중량 짊어진 채로 비등비등 → 더 강한 진짜 실력. 그 부담을 안 했다면 더 큰 차이로 우승했을 것."

## ✅ 현재 구현 (코드)

**파일:** [src/engine/scoreItems/08_burden_weight.ts](../../src/engine/scoreItems/08_burden_weight.ts)

### 알고리즘: 보정 착순 (handicap-adjusted ord)

```
보정 착순 = 실제 착순 - (내 부담중량 - 그 경주 평균 부담중량) × α
α = 0.5  (1kg 당 0.5위 보정)
```

### 예시

| 케이스 | 실제 착순 | 부담 | 평균 부담 | 보정 착순 | 해석 |
|---|---|---|---|---|---|
| A | 3위 | 58kg | 55kg (+3) | 3 - 1.5 = **1.5위** | 사실상 강자 |
| B | 3위 | 52kg | 55kg (-3) | 3 + 1.5 = **4.5위** | 사실상 평범 |
| C | 1위 | 60kg | 55kg (+5) | 1 - 2.5 = **-1.5위** | 압도적 강자 (1.0 clamp) |

### 점수 변환

과거 5경주의 보정 착순 평균 → 정규화 (1위 = 1.0, 10위 = 0.0).

```
score = 1 - (avgAdjusted - 1) / 9
clamp to [0, 1]
```

## ⚠️ 알려진 한계 / 향후 개선

### 1. α=0.5 휴리스틱

"1kg 당 0.5위" 보정 계수는 임의 설정. 실제로는 거리/등급별 다를 수 있음.
→ 향후 학습으로 α 자동 조정 가능 (현재 휴리스틱).

### 2. 직전 단일 경주가 아닌 5경주 평균

최근 1경주 부담중량만 반영하면 노이즈 큼. 평균이 안정적. 단 5경주 중 부담중량 변화 큰 경우 (강자 → 등급 강등) 평균이 흐려질 가능성.

### 3. raceAvgBudam fetch 비용

각 과거 경주마다 "그 날의 다른 출전마들 부담중량 평균" 을 별도 fetch → DB 호출 비용 증가 (n+1).
→ 백필 시간 약 5분 (수용 가능 수준).
