```

  → 평균보다 가벼우면 유리
  → 평균보다 무거우면 불리
```

## 🧮 알고리즘 (전문가 자문 대기)

```javascript
// 예시 알고리즘 (자문 후 확정 필요)
function calculateBurdenWeightScore(myBudam, raceHorses) {
  // 같은 경주 출전마들의 평균 부담중량
  const avgBudam = avg(raceHorses.map(h => h.wgBudam));
  
  // 차이 (음수 = 가벼움 = 유리)
  const diff = myBudam - avgBudam;
  
  // 점수 변환 (전문가 자문 필요)
  if (diff <= -3) return 1.0;     // 평균보다 3kg+ 가벼움 = 유리
  if (diff <= -1) return 0.75;
  if (diff <= 1) return 0.5;       // 비슷
  if (diff <= 3) return 0.25;
  return 0.0;                       // 평균보다 3kg+ 무거움 = 불리
}
```
