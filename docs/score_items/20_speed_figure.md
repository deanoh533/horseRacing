## 0. 베팅 용어 정의 (SSOT — 헷갈리지 말 것)

> ⚠️ 기존 코드/문서가 "1순위 예측마가 3등 안"을 **"복승"이라 잘못 불렀음** (2026-06-03 사용자 정정).
> 그건 단일마라서 **연승**이 맞다. 진짜 복승은 2마리 베팅이다.

| 베팅 | 정의 | 마릿수 | 순서 |
|---|---|---|---|
| **단승** | 1마리가 **1등** | 1 | — |
| **연승** | 1마리가 **3등 안** | 1 | — |
| **복승** | 2마리가 **1·2등** | 2 | 무관 |
| **쌍승** | 2마리가 **1·2등** | 2 | 순서대로 |
| **복연승** | **3등 안 말 중 2마리** | 2 | 무관 |
| **삼쌍승** | 3마리가 **1·2·3등** | 3 | 순서대로 |
| **삼복승** | **3등 안 3마리 모두** | 3 | 무관 |

→ 워크포워드의 단일마 1순위 지표는 **단승(ord==1)·연승(ord≤3)** 이 정확한 이름. (ord≤2는 단일마 베팅명이 없어 "2착내" 참고치.) **복연승·삼복승**은 다마리라 "상위3 묶음 교집합" 분석이 대응.

## 1. 무엇을 측정하나

거리·주로를 보정한 **절대 빠르기**(class figure). 약한 상대를 이긴 말과 강한 상대와 접전한 말을 구분 → 시장(배당)이 보는 "능력"과 같은 차원.

## 2. 왜 작동하나 (직관)

- 1200m 70초 vs 1800m 110초는 직접 비교 불가(거리가 다름).
- "그 거리·주로에서 보통 우승마가 몇 초"(= **par-time**)를 먼저 구하고, 각 말을 **par 대비 비율**로 환산하면 거리 달라도 같은 잣대로 비교 가능.
- 강한 클래스(국1)는 시간이 빨라 par 대비 비율에 **클래스가 자연히 녹아든다** → 절대 능력지수.

## 3. 산식

```
figure(말, 경주) = par_time(버킷) / rc_time(말)
  버킷 = (meet × rc_dist × track_type),  par_time = 그 버킷 우승마(ord=1) 평균 완주시간
abilityRaw = 최근 N(=5)경주 figure 평균   ← 반드시 as-of(과거 경주만, 누수 차단)
rawScore   = clamp((abilityRaw - 0.939) / (1.005 - 0.939), 0, 1)   ← 전역 p5/p95 매핑
이력 없음 → 0.5 중립
```

- **전역 매핑**(경주 내 percentile 금지 — 그래야 클래스 신호 보존).
- LO=0.939·HI=1.005: probe(n=4318) p5/p95 실측. par는 전 기간 1회 계산(공유 분모라 누수 없음).

## 4. 검증 결과 (2026-06-03, walk-forward out-of-sample, n=2529, 후보 v3 vs 챔피언 v1)

- **항목 단독 ρ = 0.271** (누수수정 후 정직 데이터 n=2857, 전체 4위 신호: 후반순위 0.311·부담중량 0.301·착순추세 0.275·**속도지수 0.271**)
- 후보 v3 = 전체 ρ 재학습(20 포함), 가중치 9.37(3위)

| 지표(단일마 1순위) | v1 | **v3 (+⑳)** | 시장(인기1위) |
|---|---|---|---|
| **연승**(3착 내) | 57.7 | **61.2 (+3.6%p)** | 68.8 |
| 단승(1착) | 27.9 | 30.3 | 37.8 |
| 2착내(참고) | 44.6 | 48.3 | 56.5 |

- **6개 분기 전부 v3 우세.** +3.6%p는 표본오차(±1.9%p) 밖 = 유의미.
- **시장 연승 격차: v1 -11.1%p → v3 -7.5%p** (3.5%p 따라잡음).
- **불일치 구간**(모델1순위≠인기1위): 엇갈릴 때 우위 v1 -22.2%p → v3 -16.2%p.
- **순위별 연승 3순위: v3 40.6 vs 시장 40.3 → 처음으로 시장 추월.**
- 상위3 묶음(삼복승/복연승 대응): v3 1.52 vs 시장 1.65마리.

→ 전체적으론 아직 시장 미달(연승 -7.5%p)이나, **항목 고도화가 실제로 시장 격차를 좁혔다.**
