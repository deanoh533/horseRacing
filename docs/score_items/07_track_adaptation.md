# ⑦ 주로 적응

**18개 항목 중 비중 (PRD 초기):** 8.77점
**학습 가중치 (2026-05-25):** 0.29점 ⚠️
**최신 학습 ρ:** +0.006 (사실상 노이즈)
**카테고리:** 조건
**상태:** ⏸ 데이터 부족 (같은 주로 이력 5경주 중 평균 1-2개)
**최근 업데이트:** 2026-05-26 (PRD 동기화)

> ⚠️ 알고리즘은 PRD 원문이지만 ρ ~ 0. 주로 종류가 4-5개로 분산되어 같은 주로 이력이 통계적으로 의미 있는 수준 (3+) 인 horse 가 드물음.
> 향후 데이터 누적 또는 fallback 로직 (예: 비슷한 주로 그룹화) 검토.

## 🎯 정의

**"이 말이 이 주로 상태에서 평소보다 강한가" - 향상도 측정**

```
핵심 원칙:
  ⭐ 다른 항목과 다른 차원: "변동성" 측정
  ✅ 평소 평균 대비 이 주로에서의 성적
  ✅ 약자 말도 특정 주로에서 강할 수 있음 발견
  ✅ 주로 종류만 매칭 ("건조 (2%)" = "건조")
```

## 🧮 알고리즘 (PRD v4.0 유지)

```javascript
function calculateTrackAdaptationScore(horseHistory, today) {
  // 주로 종류 매칭 ("건조 (2%)" → "건조")
  const todayTrackType = extractTrackType(today.track);
  const sameTrack = horseHistory.filter(r => 
    extractTrackType(r.track) === todayTrackType);
  
  if (sameTrack.length === 0) return 0.5; // 데이터 없음
  if (horseHistory.length < 3) return 0.5; // 전체 데이터 부족
  
  // 향상도 = 전체 평균 착순 - 해당 주로 평균 착순
  // 양수 = 이 주로에서 평소보다 좋음
  const overallAvgOrd = avg(horseHistory.map(r => r.ord));
  const sameTrackAvgOrd = avg(sameTrack.map(r => r.ord));
  const improvement = overallAvgOrd - sameTrackAvgOrd;
  
  // 점수 변환
  if (improvement >= 2.0) return 1.0;   // 매우 강함
  if (improvement >= 1.0) return 0.75;  // 강함
  if (improvement >= 0) return 0.5;     // 평균
  if (improvement >= -1.0) return 0.25; // 약함
  return 0.0;                            // 매우 약함
}

function extractTrackType(track) {
  // "건조 (2%)" → "건조"
  return track.replace(/\s*\([^)]*\)/, '').trim();
}
```

## 📊 시나리오별 점수

| 말 (오늘 "건조" 경주) | 평소평균 | 건조평균 | 향상도 | **점수** |
|---------------------|---------|---------|--------|---------|
| 강자 말 (평소 1.5위, 건조 1.2위) | 1.5 | 1.2 | +0.3 | **0.5** (평균) |
| 약자 말이 건조에서만 잘함 (평소 5위, 건조 2위) | 5 | 2 | **+3.0** | **1.0** ⭐⭐ |
| 평소 잘하던 말이 건조에서 약함 (평소 2위, 건조 4위) | 2 | 4 | -2.0 | **0.0** |
| 변화 없음 | 3 | 3 | 0 | **0.5** |
| 건조 이력 0번 | - | - | - | **0.5** (중립) |

## 💡 다른 항목과의 핵심 차이

```
거리 적성 (⑥) / 기수 폼 (⑨) / 조교사 폼 (⑩):
  - 절대 측정 (입상 비율, 우승 비율)
  - "잘하는가/못하는가"

주로 적응 (⑦):
  - 상대 측정 (평소 대비 향상도)
  - "이 조건에서 변동성이 어떤가"
  - 약자도 강점 발견 가능 (예: 비 오는 날 강한 말)
```
