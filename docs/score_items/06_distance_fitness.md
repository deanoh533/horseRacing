**상태:** ⏳ 의논 대기 (알고리즘은 작동, 도메인 미세 조정 가능)

## 📊 KRA API 필드

```
rcDist: 경주 거리 (m)
ord: 착순
```

## 🎯 정의

**"이 말이 오늘 거리에서 얼마나 잘 뛸 수 있는가" - 차등 점수 (우승력 우선)**

```
핵심 원칙 (사용자 노하우 반영):
  ⭐ 우승력이 더 중요 (1등 > 2등 > 3등)
  ✅ 차등 점수: 1=3점, 2=2점, 3=1점
  ✅ 같은 거리 정확 매칭 (1300m = 1300m)
  ❌ 단순 입상 비율 X (5번 3등 < 2번 1등이어야)
```

## 🧮 알고리즘 (확정)

```javascript
function calculateDistanceFitnessScore(horseHistory, today) {
  // 같은 거리 정확 매칭
  const sameDist = horseHistory.filter(r => r.rcDist === today.rcDist);
  
  if (sameDist.length === 0) return 0.5; // 이력 없음 (중립)
  
  // 차등 점수 (우승력 우선)
  const scoreMap = {1: 3, 2: 2, 3: 1};
  const total = sameDist.reduce((s, r) => s + (scoreMap[r.ord] ?? 0), 0);
  const maxPossible = sameDist.length * 3; // 모두 1등이면 최대
  
  return total / maxPossible;
}
```

## ⚙️ 설계 결정 (2026-05-22 확정)

| 결정 | 선택 | 이유 |
|------|------|------|
| 거리 매칭 | **정확** (1300m = 1300m만) | 다른 거리는 다른 경주 |
| 점수 계산 | **차등 점수 (3-2-1)** | **우승력 우선** (사용자 노하우) |
| 데이터 기간 | **전체 기간** | 거리 적성은 안정적 |
| 이력 없음 | **0.5 중립** | "유불리 불명" |

## 🆚 기수 폼/조교사 폼과의 차이 (중요)

```
⑨ 기수 폼 / ⑩ 조교사 폼:
  - 입상 비율 + 1등 보너스 ×0.2
  - "꾸준한 입상이 좋은 기수/조교사"
  - 5번 입상 기수 > 2번 1등만 한 기수

⑥ 거리 적성 (이 항목):
  - 차등 점수 (1=3, 2=2, 3=1)
  - "우승력이 거리 적성의 핵심"
  - 2번 1등 말 > 5번 3등 말 (사용자 의도)

→ 다른 노하우 반영
   기수/조교사: 안정성 중요
   거리 적성: 우승력 중요
```

```

   → 같은 거리라도 주로 달라 시간 차이
```
