```
이 신호는 "경주 운영 스타일 + 후반 마무리 능력"을 측정.

세 가지 유형:
  1️⃣ 추월형 (Closer): 뒤에서 출발 → 후반에 추월
     - 강한 지구력 신호
     - 신호 4 만점 가능
  
  2️⃣ 선두형 (Front-runner): 출발부터 선두 → 끝까지 유지
     - 안정적 페이스
     - 신호 4 높은 점수 (가점 포함)
  
  3️⃣ 떨어지는 말: 앞에서 출발 → 후반에 뒤로 밀림
     - 페이스 폭주 또는 체력 부족
     - 신호 4 낮은 점수
```

## 🧮 알고리즘 (선두형 가점 포함)

```javascript
function calculateLatePositionScore(recent5Races) {
  if (recent5Races.length === 0) return 0.5;
  
  const scores = recent5Races.map(r => {
    const startOrd = r.buG1fOrd;
    const finishOrd = r.buS1fOrd;
    
    // 데이터 없으면 중립
    if (!startOrd || !finishOrd) return 50;
    
    // (A) 마지막 펄롱 순위 점수 - 80%
    const ordMap = {1: 100, 2: 80, 3: 60, 4: 40, 5: 20};
    const finishScore = ordMap[finishOrd] ?? 0;
    
    // (B) 변화 보너스 (스타일 보너스) - 20%
    const change = startOrd - finishOrd; // 양수 = 추월
    let changeBonus;
    if (change >= 3) changeBonus = 100;       // 강한 추월
    else if (change >= 1) changeBonus = 50;   // 보통 추월
    else if (change === 0) changeBonus = 30;  // 위치 유지 (선두형 가점!)
    else if (change >= -1) changeBonus = -30; // 약간 밀림
    else if (change >= -3) changeBonus = -70; // 큰 밀림
    else changeBonus = -100;                  // 매우 큰 밀림
    
    return Math.max(0, Math.min(100, finishScore * 0.8 + changeBonus * 0.2));
  });
  
  // 최근 가중치 적용
  const weights = [0.4, 0.25, 0.15, 0.1, 0.1];
  const weightedAvg = scores.reduce((sum, s, i) => 
    sum + s * (weights[i] || 0), 0);
  
  return weightedAvg / 100;
}
```

## 💡 신호 2와의 차이 (중요!)

```
신호 2 (착순 추세) = 결과
  → "최종적으로 몇 위였나?"
  → ord 필드 사용
  → 결과 자체를 평가

신호 4 (후반 순위) = 과정
  → "그 결과에 어떻게 도달했나?"
  → buG1fOrd, buS1fOrd 사용
  → 운영 스타일 평가

두 신호 함께 보면 진짜 컨디션 파악:
  ✅ 1위 (신호2 만점) + 1→1 (신호4 높음) = 안정적 강함
  ✅ 1위 (신호2 만점) + 5→1 (신호4 만점) = 매우 강한 컨디션
  ⚠️ 5위 (신호2 낮음) + 5→1 추월 시도 = 발전 가능성
  🚨 5위 (신호2 낮음) + 1→5 떨어짐 = 매우 안 좋음
```

## ⚠️ 엣지 케이스

```
1. buG1fOrd 또는 buS1fOrd 데이터 없음
   → 50 (중립)으로 처리

2. 데뷔전 (이력 없음)
   → 0.5 반환

3. 출발 위치(stOrd)가 매우 불리한 경우
   → 신호 자체는 변화량 측정이므로 자동 보정됨
   → (예: 외곽 출발 → 1펄롱 후 자연스럽게 뒤쪽)
```
