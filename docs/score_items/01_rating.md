# ① 레이팅

**14개 항목 중 비중:** 20점 (최대 비중)
**상태:** PRD v4.0 그대로 (140 만점 유지 결정)
**최근 업데이트:** 2026-05-22

---

## 📊 KRA API 필드

```
rating: 정수 (0 ~ 150 이론, 실제 ~108)
rankRise: 등급 변동 (양수=상승, 음수=하락)
```

## 🎯 계산

```javascript
function calculateRatingScore(horse) {
  if (horse.rating === 0) return 0; // 6등급 미부여
  return horse.rating / 140;        // PRD v4.0 그대로
}
```

## 📊 실제 데이터 분포 (KRA 검증 결과)

```
서울 경마 최대값: ~108 (2026-04-26 기준)
부산경남 최대값: ~80
일반적 범위: 0~100
6등급 미부여: rating = 0 (다수)
```

## ⚠️ 검증 시 발견 사항

- 실제 최대값이 ~108인데 PRD는 140 만점으로 설정
- 사용자 결정: 그대로 유지 (이론적 최대값)
- 실제로는 100점이 만점에 가까운 효과
