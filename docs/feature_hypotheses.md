## 🧭 메타 패턴 (거의 모든 실패가 여기로 수렴)

1. **두 개의 천장** — ① 공개 피처는 시장 못 이김(시장 천장, −7.4~7.8%p 강건), ② 정확도는 ROI로 안 바뀜(환급률 천장). 출처 [[project_market_dominance_ceiling]].
2. **흡수(redundancy)** — 현실에선 진짜인 신호도 기존 80피처(특히 `interval_days`·`late_gain_mean`·`rating`)가 이미 담고 있어 한계기여 0. *현실의 진짜 신호 ≠ 모델 추가가치.*
3. **게이트A 통과 ≠ 안전** — 무분산 피처는 r=0으로 거짓통과. 진짜 시험은 게이트B(다분기).
4. **살아남은 단 하나의 방향** = **반공개 신호(조교 기록)** — 시장이 저평가했을 수 있고 누수 0. 현 본류. 출처 [[project_training_signals]].
