## 3. 핵심 인사이트

### 🔴 B 검증 발견 (2026-05-27, n=37,434)

1. **⑥ 거리 적성 ρ=0.586** — 한국 경마에서 거리 적합도가 다른 모든 요소를 압도. 단일 최강 신호.

2. **① 레이팅 ρ=0.078 (가중치 1위인데 ρ 13위)** — Range restriction 문제. KRA 레이팅은 클래스 진입 기준이므로 같은 경주 안에서는 이미 비슷한 레이팅끼리 경쟁 → 변별력 없음. 절대값 대신 "클래스 내 상대 레이팅" 또는 "레이팅 변화 방향" 필요.

3. **⑤ 후반순위(0.350) vs ④ 구간시간(0.060)** — 같은 구간기록 데이터인데 순위가 시간보다 5배 강함. "시간은 날씨·주로 노이즈 큼, 순위가 더 안정적" 도메인 인사이트 데이터로 증명됨.

4. **⑧ 부담중량 ρ=0.321 (임시산식인데 강함)** — KRA 핸디캡 시스템에서 강한 말이 더 높은 부담중량을 받음 → 부담중량이 말의 능력 proxy 역할. 현재 산식 방향이 맞음.

5. **⑬ 나이×거리×성 ρ=-0.017** — 음수. 이 항목이 예측을 방해하고 있음. 즉시 삭제.

6. **⑦ 주로 적응 ρ=0.032 (가중치 8.77)** — 가장 큰 가중치 낭비. 대폭 하향.

## 4. B 검증에서 확인할 사항

> B = Spearman ρ 데이터 검증 + 도메인 인사이트 검증 (열린 태도)

- [ ] **각 현재 항목의 Spearman ρ** — 실제로 착순과 얼마나 상관관계인가  
- [ ] **⑰ 배당률 ρ** — 높으면 순환참조 문제 확인  
- [ ] **⑬⑮⑱ ρ** — 낮으면 삭제 근거  
- [ ] **B (속도지수) 대안** — 우리 데이터로 구성 가능한 ability figure는 무엇인가  
- [ ] **기수·조교사 최근형 ρ** — 통산 vs 최근 3개월 중 어느 쪽이 더 강한 신호인가  
- [ ] **새로운 인사이트** — 검증 중 예상 못한 상관관계 발견 시 기록
