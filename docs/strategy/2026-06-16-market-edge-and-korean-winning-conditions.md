## Part 0 — 출발점: 우리가 이미 증명한 것

이 문서는 백지가 아니라 **우리 실측 위에서** 쓴다. 지난 세션들이 확정한 제약:

1. **두 개의 천장**
   - **시장 천장**: 공개 경기데이터 피처로는 시장(인기순위)을 못 이긴다. 연승 격차 −7.4~7.8%p, 6분기 강건. win_odds를 피처로 넣어도 부가가치 0.
   - **환급률 천장**: 정확도를 올려도 베팅 ROI로 안 바뀐다. 정확도↑ → 저배당(인기마)으로 이동 → 패리뮤추얼 공제율이 상쇄. 양성 대조군(마감배당 100% 신호)조차 박스 ROI ≈ 0.
2. **흡수(redundancy)**: 현실에서 진짜인 신호도 기존 ~80피처(특히 rating·recent_form·interval_days·late_gain_mean)가 이미 담고 있어 한계기여 0.
3. **유일하게 살아남은 방향** = **반공개 신호**(시장이 저평가 + 우리가 새로 캠). 현 본류 = 조교(training).

→ 따라서 "시장을 이기는 새 방법"은 **공개 피처 더 짜기**가 아니라, **방법론 자체를 바꾸는 것**이어야 한다.

## Part A — 시장을 이기는 AI 방법론 (전문가 관점)

### A1. 패리뮤추얼의 근본 정리
파이를 나눠 갖는 패리뮤추얼에서 순수익 조건은:
> **내 확률추정이 군중(최종배당)보다 "공제율 t 이상" 더 정확할 때만** 이긴다.

최종배당은 수만 명의 베팅이 응축된 **매우 강한 추정기**다. 즉 "최종배당 ≈ 진실확률"에 가깝고, 우리가 그걸 t만큼 능가해야 한다. **KRA 공제율(✅ 검증): 단승·연승(win/place) 20%(환급 80%) / 그 외 전 베팅종류 26%(환급 74%).** 이게 우리 "환급률 천장"의 정체 — 베팅 1건당 평균 −20~26%에서 출발.

### A2. 프로 신디케이트가 실제로 이기는 3경로 (Benter·Woods·Bossaerts 계열)
| 경로 | 내용 | 우리 현황 |
|---|---|---|
| **① Benter 2단계 모델** | ✅ **원논문 구조 확인**: 1단계 조건부로짓(conditional logit)으로 말 "strength"(P_fund, 시장정보 *없이*) 산출 → 2단계 *두 번째* 조건부로짓이 strength + **공중 함의확률 P_mkt를 결합**해 P_final. 결합모델이 둘 단독보다 우월, 5년 운영 흑자=패리뮤추얼 비효율 증거. | ✅ **우리 win_odds=0과 구조적으로 다름.** 우리는 win_odds를 *한 모델의 피처 한 칸*으로 넣어 0. Benter는 *별도 2단계 결합모델* + **베팅/캘리브레이션 평가**. → 재도전 가치 확인(A5). |
| **② 베팅 풀 선택** | 단승·연승 풀은 군중이 날카로움(효율적). **엑조틱(쌍승·삼복승·픽N)은 조합확률이라 군중이 약함** → 프로 수익 대부분 여기서. | ⚠️→❗ **반증 발견**: KRA 엑조틱 공제율 **26% > 단복승 20%**(✅검증). 즉 한국에선 엑조틱이 *군중은 약할지 몰라도 공제 벽이 6%p 더 높다.* "엑조틱이 쉽다"는 보편론이 KRA엔 약화 적용. 단복승보다 +6%p 우위를 더 내야 본전. |
| **③ 시장 미시구조·리베이트** | 막판 배당흐름 + 리베이트(실질 공제율↓). | 리테일 한국 베터엔 **해당 없음**(구조적). |

### A3. KRA 구조적 벽 (✅ 웹 검증 완료)
- **공제율(✅)**: 단승·연승 20% / 그 외 26%. 베팅 ROI 난이도 최상 — 특히 엑조틱이 더 불리(A2②).
- **서울·부경 둘 다 모래(dirt/모래) 트랙(✅)** → 잔디 없음 확인(제주는 조랑말 dirt). dirt 특성: **선행/도주 우위, 안쪽 출발번호 유리, 페이스 압박 큼**. ← 우리 ⑲ 실측(도주+HOT 강세)과 정합.
- 출주두수 ~10~12.

### A4. 현실적 "승리" 재정의 (정직한 전문가 결론)
공개 피처 + 단승/연승 풀에서 베팅 ROI로 시장을 이기는 건 **사실상 불가**(두 천장). AI 전문가로서 현실적 승리 갈래 4개:

- **(a) 서비스로서의 캘리브레이션** — 제품 가치 = "가장 정직하고 설명가능한 확률·근거"지, 베팅 머신이 아님. 평가축을 **rank 적중률 → 확률 캘리브레이션(Brier·log-loss·reliability curve)** 으로 확장. 시장을 못 이겨도 "최고의 분석가"는 될 수 있음.
- **(b) 반공개 신호** — 조교(training)·마체중 직전수집·패독/주로상태 등 **군중이 덜 반영**하는 정보. 공개 피처 천장 탈출의 유일 경로. (현 본류)
- **(c) 조건부 엣지 마이닝** — 전 경주가 아니라 **특정 조건(신마전·다두수·특정거리·롱샷장)에서만 모델>시장**인 구간을 찾기. 모델·시장 불일치가 *맞았던* 경주의 공통특성 추출.
- **(d) Benter 2단계 제대로** — 단승풀이 안 되더라도, 캘리브레이션된 결합확률이 **특정 엑조틱/조건 부분집합**에서 +EV일 수 있음.

### A5. 우리가 덜 쓴 "AI 전문가다운" 도구
1. **캘리브레이션 평가 파이프라인** — Brier/log-loss/reliability. (이미 diag_gate_channels에 ΔBrier 일부 있음 → 정식 축으로 승격)
2. **2단계 시장결합 + Kelly EV 백테스트** — win_odds를 피처 아닌 2단계 블렌더로. 평가는 rank 아닌 EV/캘리브레이션.
3. **조건부 엣지 마이닝** — "모델 픽이 시장과 엇갈렸는데 맞은" 경주의 조건 분포 분석(부분집합 엣지).
4. **더 큰 모델·피처공간** (GBDT/얕은 NN) — 단 흡수 천장 때문에 기대 낮음. 우선순위 후순위.
5. **준지도/대조 신호 발굴** — 반공개 신호(조교)에 집중.

### B2. 한국 경마(KRA) 한정 승리 요건
보편 요인을 KRA 특성으로 좁히면:
1. **모래(dirt) 트랙 → 전법 우위가 큼**: 도주·선행이 추입보다 유리(우리 ⑲ 역전 실측과 정합). 잔디 이론(HOT→추입유리)은 한국에 안 맞음.
2. **안쪽 출발번호 우위** (모래 단거리일수록): ✅ 보편 실증 — dirt 단거리(5~7f)서 안쪽 1~3번 합산 우승 **35~38%**(거리 길수록 약화: dirt 루트선 중·외곽 5~10번 ~16%). 주 동인=첫 코너 ground-saving. KRA도 모래+단거리 多 → draw 신호 재점검 가치 높음(현 gate_relative). 단 KRA 자체 출발번호 우승분포는 별도 실측 권장.
3. **등급제 + 등급이동이 핵심**: 국산/혼합/외국산 등급, 강급(class drop)은 이미 class_move로 흡수.
4. **기수·조교사 집중도 높음**: 소수 상위가 과점 → 기수/조교사 신호 관련도 높음(이미 보유).
5. **한국 혈통 미성숙 → 혈통 약예측**: 우리 dsa 실측 ≈0과 정합. 혈통 추가투자 비권장.
6. **마체중 계량(경기 ~1h 전) 예측력 有, 단 우리 수집 타이밍 문제**: KRA 직전정보 API로 사전수집하면 반공개 엣지 가능(보류 중인 +7.2%p 후보).
7. **높은 공제율 → 베팅 ROI 트랙 음성**: 서비스 가치는 정확도/설명으로.
8. **직전정보(주로상태·기수변경·마필상태·발주직전 배당흐름) = 반공개**: 군중이 덜 반영 가능. 조교와 함께 우선 탐색군.

## Part C — 서비스 내 "승리요건 판정" 프레임워크

우리는 이미 판정 기계를 갖고 있다(게이트A/B·probe·`feature_hypotheses.md`). "승리요건 판정"은 새 시스템이 아니라 **각 요건을 이 기계에 태우는 표준 파이프라인**으로 정의한다.

### C1. 판정 파이프라인 (요건 1개당)
1. **조작화**: 요건 → as-of 측정가능 피처(누수 0: 경주 전 확정값만).
2. **커버리지**: 데이터 가용률 확인(희소하면 보류).
3. **게이트A**: 기존 ~80피처와 |r|>0.5 중복? + 분산 건강? (무분산 거짓통과 주의)
4. **게이트B(다분기)**: holdout 3면(연승·fade·복승) 개선? 단일분기 거짓양성 배제.
5. **(베팅 트랙이면) EV/캘리브레이션**: Brier·Kelly EV.
6. **판정 → 카드 기록**: 채택 / 기각 / 부분(fade 전용). `feature_hypotheses.md`.

### C2. 승리요건 판정 카드 (템플릿)
```
## [요건명]
- 가설(한 줄): 
- 도메인 근거(보편/KRA):
- 조작화(피처·as-of 정의):
- 데이터 출처·커버리지:
- 게이트A: max|r| / 중복 항목 / 분산
- 게이트B(다분기): 연승Δ / fadeΔ / 복승Δ
- (베팅) ΔBrier / Kelly EV:
- 판정: 채택 / 기각 / 부분 / 보류
- 비고(흡수 여부·재도전 각도):
```

### C3. KRA 승리요건 판정 현황표 (우선순위)
| 요건 | 상태 | 다음 액션 |
|---|---|---|
| 능력·폼·스피드·페이스·등급이동·기수·조교사 | ✅ 모델 내(판정 완료·채택) | 유지 |
| 출발번호(draw) 모래 보정 | △ 부분(gate_relative) | KRA 한정 재점검(조건부) |
| 마체중 직전수집 | ⏳ 보류(타이밍) | KRA 직전정보 API 조사(반공개 엣지) |
| 조교(training) | 🔬 진행(본류) | KRA 복구(6/17) 후 backfill→게이트 |
| 주로상태·발주직전 배당흐름 | ❓ 미시험 | 조작화·커버리지 조사 |
| 조건부 엣지(모델>시장 부분집합) | ❓ 미시험 | 마이닝 도구 신설 |
| 혈통 심화 | ⛔ 비권장 | (국산 미성숙·실측 0) |

### C4. 결론
보편 승리요건은 **거의 다 이미 모델에 흡수**돼 있다. 따라서 판정 프레임의 **진짜 가치는 ① 반공개 신호(조교·마체중직전·직전정보)와 ② 조건부 엣지**에 집중될 때 나온다. "전 경주에서 시장 이기기"가 아니라 "특정 정보/조건에서 시장이 놓친 곳"을 판정하는 도구로 쓴다.
