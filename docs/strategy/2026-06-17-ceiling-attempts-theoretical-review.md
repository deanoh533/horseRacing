## 0. 천장은 왜 존재하나 — 이론 3기둥

모든 시도를 이 세 자로 잰다. "시도가 이론적으로 옳았나"는 곧 "이 세 기둥 중 무엇을 건드렸나"의 문제.

| 기둥 | 이론 | 함의 |
|---|---|---|
| **① 군중 효율성** (efficient market / wisdom of crowds) | 최종배당 = 수만 명 베팅의 응축 → 편향 없는 강한 추정기. 이기려면 군중이 *못 본 정보* 필요 | 공개정보만으론 못 이김 |
| **② 정보 흡수** (redundancy / 조건부 독립) | 새 피처가 가치를 더하려면 기존 피처와 *결과를 두고 조건부 독립*이어야. 공개요인은 서로 상관 → ΔR²≈0 | "새 공개피처"는 대개 흡수 |
| **③ 환급률** (takeout) | 베팅 ROI = 우위 − 공제율(20~26%). 정확도↑→인기마 이동→우위 축소가 공제 못 메움 | 정확도↑가 ROI로 안 바뀜 |

**한 줄 이론:** 효율적 시장은 공개정보로 못 이긴다(①). 새 공개신호는 대개 흡수돼 있다(②). 정확도를 올려도 환급률이 ROI를 막는다(③). → **유일 탈출구 = "군중이 안 본 정보"(사설/반공개) 또는 "이기기 포기·정직성 승부".** (= Grossman-Stiglitz: 정보수집에 비용이 들면 그 비용 치른 자만 초과수익.)

## 그룹 A — "시장을 직접 이긴다" (순위·정확도)

### A1. 공개피처 종합점수 vs 인기순위 (베이스라인)
- 가설: 21항목이 인기순위보다 정확.
- 이론: ⚠️ 사전기대 약함 — 인기순위는 이미 공개정보 흡수(①).
- 결과: 연승 −7~8%p, 6분기 강건.
- **코멘트: 이론대로 음성. 방향은 옳음** — 이건 측정(기준선 −7.4%p 확립)이 목적. 안 하면 천장 높이를 모름.

### A2. win_odds를 모델 피처로 추가
- 가설: 시장정보를 모델에 직접 먹이면 보강.
- 이론: 🔶 직관 옳고 구현 틀림 — 강한 단일신호를 59개 약신호와 한 회귀에 넣으면 정규화로 희석. "결합"은 옳고 "한 칸 피처"는 틀림.
- 결과: 부가가치 0(6분기).
- **코멘트: 나중에 Benter 2단계(A6)로 교정된 중간 실패.** "결합은 맞되 방법이 틀렸다"를 입증.

### A3. 새 공개피처 발굴 (class_move·⑳속도·의료·z·구간·경쟁강도 등)
- 가설: 아직 안 담긴 공개요인이 있다.
- 이론: 🔶 흡수 천장(②)이 지배.
- 결과: **class_move·⑳만 생존**, 나머지 전부 흡수/기각.
- **코멘트: 흡수 이론의 결정적 증거.** class_move가 산 이유 = "오늘−직전 등급"은 절대능력이 아닌 *상대수준 변화* → 기존 능력피처와 **조건부 독립**(직교). 이론이 "흡수 안 될 신호=직교성"이라 예측했고 실측이 정확히 골라냄. 천장 확인 후 추가발굴은 수확체감 → 공개피처 종결.

### A4. 조건부 엣지 마이닝 (§C6)
- 가설: 평균은 못 이겨도 특정 조건(혼전·다두수·롱샷장)에선 모델>시장.
- 이론: ✅ 가장 정당한 시도 중 하나 — longshot bias 등 조건부 비효율은 문헌에 실재.
- 결과: 채택후보 0. **강한 본명 구간이 오히려 최악(−32%p).**
- **코멘트: 정보량 큰 음성.** KRA 군중은 강본명서 *특히* 정확. 핵심가설("혼전서 엣지") 정면 반증. 옳게 닫음.

### A5. 적중률 7각도 (§C9)
- **거스르기·reach(진단):** 일치구간 손실0, 전 손실이 엇갈릴 때. reach 멀수록 −9→−38%p 단조추락. 자명하나 손실 해부에 필요.
- **깜짝마 무신호:** 이론적으로 거의 동어반복적 실패("업셋"=공개정보로 예측 안 됨). 사전기대 낮음이 맞음.
- **깜짝마-only 학습:** 같은 결론.
- **카스케이드/앙상블:** 🔴 사전에 회의했어야. 부스팅·배깅은 오류 *독립*이 전제인데 A·B 같은 공개피처 → 오류 상관 → 가정 붕괴. 블렌드 이득 0. 이론이 실패 예견 가능(사용자 가설이라 검증은 협업상 옳음).
- **조건별 강점:** 통제 후 부호반전=노이즈. multiple testing→거짓양성. 2년 OOS 통제가 올바른 반증.

### A6. Benter 2단계 (2026-06-17)
- 가설: 시장을 베이스로 모델이 *직교 정보*를 더한다(b>0).
- 이론: ✅✅ 사전기대 최고, 유일하게 진짜 열려있던 문. Benter 5년 흑자=가능 입증. A2의 설계결함(피처 한 칸)을 교정(별도 2단계 결합 + 경쟁구조 보존).
- 결과: b≈0(logistic 0.13, 적중률 동률·분기 감쇠), GBDT는 합치면 붕괴(과적합).
- **코멘트: 가장 가치 있는 음성.** Benter와 차이가 이론을 완성 — Benter의 strength는 시장無 거대 사설 피처공간 + 홍콩(비효율 시장), 우리는 공개피처 + 효율시장. 이론은 "직교정보 있으면 b>0"인데 **우리 공개피처엔 시장 밖 직교정보가 없었다.** 기둥①을 가장 직접 시험해 닫음.
- 실측 로그: `docs/benter_twostage_20260617.txt`. 코드: `src/engine/eval/benter.ts`, `scripts/benter_twostage.ts`(`npm run benter`).
- **B-2 유의성 추가검증 (2026-06-18, `docs/benter_significance_20260617.txt`):** logistic b가 "노이즈인가"를 두 각도로. ① OOS 페어드 부트스트랩(합성−시장, 경주별 Δ=ln우승확률, n=2,559): 평균 Δ=+0.00035, **95% CI [−0.0034,+0.0040] → 0 포함**, p(Δ≤0)=0.43 = **노이즈와 구분 불가**. ② 분기별 b 부호검정: 6/6 양수(부호검정 p=0.031)이나 감쇠(0.318→0.130). **정밀 사망진단: b는 in-sample서 방향 일관 양수("희미한 속삭임")이나 OOS 크기가 0과 구분 불가·적중률 이득 0·시간 감쇠 → 실용적 null 확정.** 두 검정이 다른 질문(②=신호 방향 존재? ①=실제 도움?)에 답하며, 엣지 판정엔 ①이 결정적.

## 그룹 B — "베팅 ROI로 이긴다"

### B1. 벤터 혼합 / value betting / combo betting
- 가설: 모델 확률로 +EV 베팅 선별.
- 이론: ⚠️ 환급률 천장(③)에 수학적으로 막힘. 정확도 천장(A) 미돌파 시 ROI = 우위 − 20~26% 음수 강제.
- 결과: 혼합 ROI −28%, **양성대조군(마감배당 100% 신호)조차 박스 ROI ≈ 0.**
- **코멘트: 이론대로. 양성대조군 0 = 우리 모델 문제가 아닌 구조의 벽.** 천장 확인 전이라 시도는 정당.

## 그룹 C — "이기길 포기·정직성/서비스로 승부" (방향 전환)

### C1. 캘리브레이션 평가축 (§C7)
- 가설: 못 이겨도 "정직한 확률"은 제품가치.
- 이론: ✅ 올바른 재구성 — Brier 분해상 reliability(정직성)와 resolution(이김)은 별개 축.
- 결과: 모델 ECE 0.017(꽤 정직), 시장 0.004(더 정직).
- **코멘트: 평가 목표를 옳게 분리한 전환점.** 제품 기반 성립.

### C2. Platt/isotonic 재보정 (§C8) — **유일한 양성**
- 가설: 모델의 "본명 과소확신" 편향을 사후보정.
- 이론: ✅✅ 가장 견고 — 캘리브레이션은 단조변환으로 사후교정 가능, 변별력 불변.
- 결과: **ECE 0.017→0.004(시장 동률).** 첫 채택후보.
- **코멘트: 이론·결과 완벽 정합.** 뉘앙스: Brier·log-loss(예리함 포함)는 여전히 시장 우세 → "정직해졌지만 더 예리해진 건 아님"(Murphy 분해 산 예시). "확률을 믿을 수 있게"이지 "시장을 이김"이 아님.

## 그룹 D — "군중이 안 본 정보" (반공개 — 이론상 유일 생존 본류)

### D1. 마체중 직전수집
- 가설: 계량 체중(~1h 전)은 컨디션 신호, 군중이 덜 반영.
- 이론: ✅ 방향 옳음(시장 밖 정보) / ⚠️ 누수 위험(경기후 수집=미래).
- 결과: +7.2%p였으나 라이브 누수 의심 보류.
- **코멘트: as-of 수집만 해결하면 진짜 후보.**

### D2. 조교(training) 신호 — 현 본류
- 가설: 훈련 기록은 군중이 거의 안 보는 반공개 정보.
- 이론: ✅✅ Grossman-Stiglitz가 가리키는 정확히 옳은 방향 — 군중이 *비용 때문에 안 모으는* 정보가 엣지.
- 결과: **흡수 확정(2026-06-19) — 채택 X.** 갭 메운 풀 커버리지(2025-06~2026-06) 후 게이트B 연승 +1.8%p 재현(top3 항목)이나, **통제 A/B**(같은 logistic top3, 조교 ON/OFF만 토글, 6분기 OOS): 연승 Δ **−0.12%p**(분기 3+/3− 혼재), 단승 −0.04%p. 기록 `docs/train_signal_ab_20260619.txt`.
- **코멘트: 내가 예고한 D2 흡수위험이 실현됨.** "조교가 recent_form과 조건부 독립인가"의 답 = **아니오, 흡수**. 기존 ~80피처(recent_form·late_gain 등 피트니스)가 이미 담음. **게이트B(+1.8%p, 한계기여) vs 통제 A/B(−0.12%p) 괴리 = 메타패턴 #2(실측신호≠모델 추가가치, draw×거리 §C5와 동형). 교훈: 채택 판정은 게이트B가 아니라 통제 A/B(같은 스펙 토글)로 해야 한다.** 조교의 *다른* 조작화(recent_form이 못 담는 각도)는 미시험으로 남으나 흡수 입증 후라 기대 하향.

## 메타 검증 — 전체 탐색 전략은 옳았나?

**옳았던 점:**
1. 천장을 추측이 아닌 **측정으로 봉인** — 이론기대가 낮아도 한 번은 측정해야 확정.
2. 3기둥을 점진 분리 — 어디서 막히는지(효율성/흡수/환급률) 정확히 짚음.
3. 방향 전환이 이론적으로 정확 — (C)정직성 + (D)반공개는 이론이 가리키는 바로 그 두 출구.

**비판할 점:**
- 흡수 천장 확인 후에도 공개피처·적중률 각도를 여러 번 더 돌림 = 수확체감. 단 경험적 확정 + 사용자 가설 검증 가치로 전면 비판은 아님.
- **최고 가치 = A6(Benter, 유일 열린 문을 닫음) + C2(Platt, 유일 양성).** 나머지는 대체로 예견된 음성의 확정.

## 이론적 결론

천장은 실재하며 이론이 예측한 그대로(①효율 + ②흡수 + ③환급률). 그룹 A·B의 "공개정보로 이기기"는 이론상 실패 예정이었고 측정으로 봉인한 건 옳은 과학(특히 A4·A6은 진짜 열린 문이라 검증 필수). **이론이 허용하는 출구는 둘** — C2(사후 캘리브레이션=정직성) + D2(사설/반공개 정보=조교, Grossman-Stiglitz).

**2026-06-19 갱신:** D2(조교)가 **흡수로 판명**(통제 A/B 연승 Δ −0.12%p). 즉 *공개·반공개를 막론하고 기존 피처에 직교하지 않는 신호는 전부 흡수*된다는 게 더 강하게 확증됨(흡수 천장이 정보 출처가 아니라 **직교성**의 문제임). **현재 유일하게 통제까지 통과한 양성 = C2(Platt 캘리브레이션, 정직성/서비스).** "이기기" 트랙은 — 조교조차 막힌 지금 — *recent_form 등이 못 담는 진짜 직교 정보*(조교의 다른 조작화·마체중 직전수집·발주직전 배당흐름)를 찾기 전엔 후보 없음. **방향 권고: 서비스 캘리브레이션(C2)을 제품 가치로 확정 + 직교성 사전검증(게이트A |r| + 통제 A/B)을 모든 신규 신호의 채택 관문으로.**
