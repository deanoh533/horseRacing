## 단승 기준선 첫 측정 (2026-09-22, `feat/win-baseline`)
벤치마크가 모델 단승을 집계만 하고 출력하지 않던 것을 고쳐(롤링 단승율 표 + 시장 진단 단승) 처음 측정. 같은 6분기 롤링, 2,617경주.

| | 단승(1순위 1착) | 연승(1순위 3착내) |
|---|---|---|
| 시장(인기1위) | 37.4% | 68.8% |
| 챔피언(라이브 v7 그대로 — ⚠️ 2022-01~2026-06 학습이라 시험분기 in-sample, 낙관치) | 31.0% (**−6.4%p**) | 61.9% (−6.9%p) |
| Logistic(t1) | 31.5% | 60.4% |
| Logistic(t3) | 30.6% | 60.7% |

- 상대 격차는 단승이 더 큼 — 시장 대비 83%(단승) vs 90%(연승).
- 엇갈릴 때(1,063건) 모델픽 단승 17.2% vs 인기픽 33.0% — 연승보다 더 크게 짐.
- 방식: 데이터 2024-01~, 시험 분기마다 그 이전 경주만으로 재학습(확장 윈도우, 2025Q1 학습 1,774경주 → 2026Q2 3,984경주). 챔피언만 재학습 없이 저장된 v7을 그대로 채점. 롤링 모델의 피처 선택은 게이트B holdout 2025Q4(시험 구간 안) 기준이라 약한 선택 누수 있음.
- 정직한 비교는 롤링 모델끼리: 1착 라벨(t1)이 t3보다 단승 +0.9%p(5/6분기 양수). 챔피언과의 비교(+0.5%p)는 챔피언이 in-sample이라 무효. **라벨 교체 여지는 ~1%p 수준 — 격차 6.4%p의 대부분은 정보 차이**(연승과 같은 그림). 사후 관찰이라 채택 근거 아님(하려면 단승 지표로 사전등록).

> 후속(2026-09-22): 당일 마체중(`wg_hr`, 라이브 미가용)이 학습·벤치에 섞여 있던 것을 `--exclude-feature`로 통제 A/B → **Δ 노이즈 범위(효과 없음)**. 위 단승·연승 수치는 이 누수로 부풀지 않았다. 상세 [04-signals](04-signals.md).
