## UI/UX 정합 감사 (2026-06-29)
앱 직접 구동 후 4화면 캡처 검토. 시트·강추엔 현 모델 산출물(우승%·연승%·선별표시) 정상 반영.

**고친 것:**
- 대시보드 모델 카드 교체(위 현재상태 참고).
- `/picks`·대시보드 "오늘/이번주 강추"에 결과 미동기화 과거예측(2024~2026 누수)이 섞이던 문제 → 당시 "최근 미확정 개최일 −7일 이내" 임시 방어 필터 → **2026-07-11 근본 해결**: L-001 완료(dailySync가 predictions 미덮어쓰기 + actual_ord만 기록)로 `useUpcomingPicks`는 `race_date=오늘` 단일 필터로 교체(경주 당일에만 표시, 커밋 5be3dcc).
- 통계 레거시 Spearman 섹션 명시("가중치 학습 이력 (레거시)", "항목별 예측력 (Spearman ρ · 레거시 진단)") — 라이브는 로지스틱.
- **항목명 맵 통합**: Statistics·Dashboard가 각자 17개 부분 맵을 들고 드리프트하던 것 → 클라 단일 출처 `client/src/lib/itemNames.ts`(정본 22개, 백엔드 `src/types/index.ts` 미러). 새 항목 추가 시 양쪽 갱신.

- 종합점수 표시 포매터 `fmtScore`(sectional.ts): logit이 0 중심 상대값이라 부호 명시(+0.3/−0.1)·−0.0→0.0 정규화. 7개 화면 total_score + HorseDetail 항목기여 일괄 적용.

- **종합점수 막대 = 연승확률 p_top3 재정의(2026-06-30)**: PredictionSheet 두 막대가 logit total_score를 0~100 스케일로 그려 항상 빈 막대였던 버그 수정. `ScoreBar`는 이제 `frac`(0~1) 채움량을 직접 받고 `p_top3`로 그림(포디엄·per-row 둘 다). null이면 빈 막대. 옆 숫자는 종합점수(logit) 그대로, 막대만 확률. logit은 0 중심 상대값이라 절대 채움 의미가 없어 확률로 그리는 게 정합. 막대=확률·숫자=점수·뱃지=선별로 역할 분리.

**잔여(미수정):**
- 통계 `/stats`는 predictions 전수 스캔 = egress 큼(라이브 캡처 미수행). 운영전환 시 집계 캐시/뷰 검토.
