- `/picks` '오늘의 강추' 뷰 + `PickBadge` 강추/주목 칩 + 통계 "선별 적중률" 섹션.
- **대시보드 최상단 = 예측 모델 카드**(2026-06-29): 옛 'Spearman 가중치 상위 4' 패널은 죽은 mock였음(로지스틱은 `weights={}`, 계수는 artifact) → 최근 N경주 복승권 적중률·이번주 강추/주목 수·`/picks` 링크로 교체.
- 로딩 스켈레톤(U-001), RaceInfoBlock 공통 헤더(3화면 공유), JockeyPanel·HorsePanel 개선 완료.

## UI/UX 정합 감사 (2026-06-29)
앱 직접 구동 후 4화면 캡처 검토. 시트·강추엔 현 모델 산출물(우승%·연승%·선별표시) 정상 반영.

**고친 것:**
- 대시보드 모델 카드 교체(위 현재상태 참고).
- `/picks`·대시보드 "오늘/이번주 강추"에 결과 미동기화 과거예측(2024~2026 누수)이 섞이던 문제 → `useUpcomingPicks`에 "최근 미확정 개최일 −7일 이내" 필터. 근본 차단은 L-001(prediction_logs).
- 통계 레거시 Spearman 섹션 명시("가중치 학습 이력 (레거시)", "항목별 예측력 (Spearman ρ · 레거시 진단)") — 라이브는 로지스틱.
- **항목명 맵 통합**: Statistics·Dashboard가 각자 17개 부분 맵을 들고 드리프트하던 것 → 클라 단일 출처 `client/src/lib/itemNames.ts`(정본 22개, 백엔드 `src/types/index.ts` 미러). 새 항목 추가 시 양쪽 갱신.

- 종합점수 표시 포매터 `fmtScore`(sectional.ts): logit이 0 중심 상대값이라 부호 명시(+0.3/−0.1)·−0.0→0.0 정규화. 7개 화면 total_score + HorseDetail 항목기여 일괄 적용.

**잔여(미수정):**
- ⚠️ **종합점수 막대 스케일 버그**: PredictionSheet `ScoreBar maxScore={100}`(304행)·per-row 막대 `Math.min(pScore,100)%`(1042행)가 logit(~−0.3~0.8)을 0~100 스케일로 그려 **항상 거의 빈 막대**. 막대 의미 재정의 필요(p_top3 연승확률 채움 vs sigmoid(logit) vs 제거) — 설계 결정.
- 통계 `/stats`는 predictions 전수 스캔 = egress 큼(라이브 캡처 미수행). 운영전환 시 집계 캐시/뷰 검토.
