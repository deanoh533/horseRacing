## UI/UX 정합 감사 (2026-06-29)
앱 직접 구동 후 4화면 캡처 검토. 시트·강추엔 현 모델 산출물(우승%·연승%·선별표시) 정상 반영. **잔여 불일치(미수정):**
- 통계 페이지가 여전히 "Spearman 기반"·"21개 항목 Spearman ρ"로 프레이밍 — 모델은 로지스틱 직접학습(레거시). weight_history 비면 빈 박스.
- 항목명 맵 17개(`ITEM_NAMES`/`ITEM_LABELS`) ≠ "21개" 라벨 — class_move·㉚속도지수·주행성향 신규항목 raw id 노출 가능.
- 점수 "-0.0점"·음수 표시(로지스틱 logit이라 정상이나 "점" 단위 오해 여지).
- **고친 것**: `/picks`·대시보드 카드의 "오늘/이번주 강추"에 결과 미동기화 과거예측(2024~2026 누수)이 섞이던 문제 → `useUpcomingPicks`에 "최근 미확정 개최일 −7일 이내" 필터. 근본 차단은 L-001(prediction_logs).
