- **v7-shape 승격 반영 (2026-07-10)** — 랭킹 모델 v6→v7 교체([[project_race_shape_track]], SSOT [02-model-benchmark](02-model-benchmark.md))에 맞춰 Platt 재적합: platt3 a=1.057·b=0.047(거의 항등, renormWin=false). `probe:picks` 재실측 0.75↑ 74.6%·0.70↑ 68.5% → **기존 임계 0.72/0.62 그대로 유효**, 캘리브레이션·선별표시 코드/설정 변경 없음. 남은 것: 주말부터 v7 기반 선별 적중률 라이브 추적.

## 복승 박스 두수 스윕 (2026-08-23) — 흑자 두수 없음, 기각 ❌

`/picks` 라이브 45경주로는 판정 불가한 질문("상위 몇 두를 박스로 사야 하나")을 과거 대표본
walk-forward(분기마다 그 분기 이전 데이터로만 재학습)로 판정. 2,382경주(2025Q1~2026Q2).
도구: `npm run backtest:box:size` + `settleBoxN`(비용 = 실제 조합 수 `C(k,2)`).

| 박스 | 적중률 | ROI | 분기별 부호 |
|---|---|---|---|
| 상위2 | 12.1% | **−30.3%** | 6/6 음수 |
| 상위3 | 28.1% | −18.7% | 5/6 음수 (2025Q3만 +12%) |
| 상위4 | 44.6% | −17.9% | 6/6 음수 |
| **상위5** | 58.1% | **−15.2%** ← 최선 | 6/6 음수 |
| 상위6 | 69.0% | −22.3% | 6/6 음수 |

- **흑자 두수 없음** — 최선(상위5)도 −15.2%, 전 분기 음수. [[project_selective_picks]]의
  2026-06-27 "공개정보 ROI 흑자 불가" 결론이 **두수 축에서도 재확인**.
- 단 **선별력은 실재**: 복승 환급률 기준선 −20% 대비 상위4·5는 그보다 나음(−17.9·−15.2%).
  "아무 조합이나 사는 것보다는 낫지만 공제율 벽을 못 넘는다" = [[project_benter_blend]]와 같은 그림.
- **ROI 곡선이 U자** — 너무 좁으면 적중률이 안 나오고(상위2), 너무 넓으면 조합 수가 수익을
  잡아먹는다(상위6 = 15조합). ⚠️ **적중률만 보면 상위6(69%)이 압도적인데 ROI는 뒤에서 두 번째**
  — 비용을 조합 수로 정산하지 않으면 정반대 결론이 난다.
- ⚠️ 사후 확정배당 = 내 베팅의 배당 희석 미반영 → **낙관적 상한**. 실제는 더 낮다.
- **2026-06-27 `probe:picks:box`와 교차 일치** (아래 "강추 조합(복승) ROI" 항목): 적중률
  13→27→43%(당시) vs 12.1→28.1→44.6%(이번)로 거의 동일. ROI는 이번이 조금 더 나쁜데
  (−24/−17/−14 → −30.3/−18.7/−17.9), **분기별 재학습 + 조합 수 비용 정산**을 넣은 쪽이
  더 정직하기 때문. 두 방법이 같은 결론에 도달 = 이 갈래는 **재확인 완료, 다시 열 이유 없음**.
  이번 작업의 순증분은 **n=5·6까지 확장**해서 U자 형태(최적점 5두, 그래도 적자)를 확인한 것.

## 알파 3중 재검증 (2026-07-06) — 총량·구간·비선형 전부 확인, 완전 종결 ❌
오프셋 조건부 로지트(배당 log-확률 계수=1 고정, β=0이면 날배당 정확 재현 자체검증됨) 프레임으로 "공개피처로 시장을 이기나"를 세 방향에서 마지막으로 재확인.
- **총량** (`npm run probe:alpha`): 시장+피처가 3개 컷오프 전부 시장보다 **악화**(Δ 전부 양수, CI도 양수 — 알파 없음을 넘어 노이즈에 오버핏).
- **구간분해** (`npm run probe:alpha:bands`): 배당 5구간(인기~대박)으로 쪼개도 강건한 국소 알파 **없음**. 우연히 이긴 칸이 1~2개 있었지만 3컷오프 동시 통과 못 해 다중비교 가드 탈락.
- **비선형** (`npm run probe:alpha:gbt`): 얕은 트리+조기종료 부스팅도 거의 학습을 못 함(라운드 1~7개, testΔ≈0) — 과적합 없이 깨끗한 음성. 선형이 못 잡는 상호작용도 없음.
→ 6/16·6/27 결론("공개피처로 시장 못 이김")이 선형/비선형/전체/구간 4방향 모두에서 재확인됨. **이 질문은 더 이상 열어둘 이유 없음.**

## 배당 블렌드 후보 (2026-07-06) — 보류(라이브 데이터소스 없음) 🔚
⚠️ 위 "시장 못 이김"과 다른 질문이었음: 배당을 재료로 넣으면 **모델 단독보다** 좋아지는가.
- `npm run probe:blend` / `probe:blend:picks`: 블렌드가 모델 단독 대비 1픽 연승 +7.1~11.5%p, ECE 반토막, 강추(P≥0.72) 픽수 9배(98→893)에 정확도까지 개선(72.4→77.3%). **수치 자체는 유효.**
- **막힌 지점 — 데이터 가용성**: `docs/prediction_mode.md`에 이미 기록된 원칙대로 당일 `win_odds`는 경주 1~2시간 전에야 채워짐. "사전/사후 동일 산식" 원칙(`docs/working_style.md` §6) 때문에 사후 백테스트에서도 당일 배당 미사용 — 이번 probe는 사후 확정치로만 검증, 실제 배포 가능한 시점(출마표 발표~경주 임박)엔 데이터가 없음.
- data.go.kr 공공데이터포털 조사 결과 KRA 배당 관련 API는 전부 "확정배당율"(경주 후) 뿐 — **경주 전 실시간/예상 배당 공식 API 확인 안 됨** (race.kra.co.kr 웹 스크레이핑은 이용약관·기술 문제로 별도 검토 필요, 미착수).
- **결정: 보류.** 운영 모델·선별표시 변경 없음. 코드(`offsetClogit.ts`·`offsetGBT.ts`·probe 6종)는 향후 실시간 배당 소스가 확보되면 재검토할 자산으로 보존.

## 조건부 엣지 마이닝 (2026-06-27) — 종결, 음성 ❌
`npm run mine:edge` (모델top1 vs 인기top1 불일치 경주를 배당대·출주두수·거리·불일치강도 구간별 placeEdge). **채택후보 0건.** 거의 전 구간에서 모델 픽이 시장 픽보다 3착내 −15~−38%p 낮음(엇갈리면 어떤 조건서도 시장 승). 양수 칸은 전부 n<20·유효분기 0 표본부족. **결정적: in-sample(누수=낙관 상한)인데도 0후보 → walk-forward 불필요(더 나쁠 뿐).** 공개피처 ROI 갈래 완전 소진(단·연승 적자/복승 OOS −24.4%/win_odds 0/조건부 0).

## 강추 OOS 재검증 (2026-06-27) — 73% 정직 확인 ✅
`npm run probe:picks:oos` (walk-forward, train<20250101→test, Platt도 train만 적합). **선별 적중률은 누수 부풀림 아님:**
- 강추 연승(ord≤3) **OOS 72.4%** (출하 in-sample 73.1%) · 주목 **OOS 67.8%** (출하 65.4%) · 베이스 28%. → 라이브 기능 검증 정직.
- 한계 적중률(말 1마리 top3)은 누수에 강건. 누수는 *조합 선택*만 오염(아래).

## 강추 조합(복승) ROI (2026-06-27) — 엑조틱도 천장, + 누수 버그 발견
- 복승(2마리 정확히 1·2착) OOS top-2: **ROI −24.4%**(6분기 전부 음수, 평균배당 5.8x). 강추박스는 n=9 무신호. **베팅 ROI 트랙 공개피처로 종결.**
- ⚠️ **predictions 테이블 p_top3 = in-sample 누수**(사후 backfill). in-sample top-2 복승은 +230%(평균배당 22.4x = 결과를 본 모델이 고배당 조합 선점)였으나 OOS로 −24.4%. **베팅 백테스트는 predictions 테이블 금지, walk-forward 필수.** 단·연승 ROI(−10.9%)는 누수가 도와도 적자라 결론 안전.
- **복승 박스(OOS, `npm run probe:picks:box`):** top2/3/4 박스는 박스 키울수록 적중률↑(13→27→43%)이나 회수배수<1(0.76→0.86)·ROI −24→−17→−14%로 **개선만, 흑자선 못넘음**(공제 벽). 박스 더 키우면 "전마 매수"=takeout 바닥 수렴. 확신선별 박스(p_top3≥0.6) +9.6%는 **2025-Q1 한 분기(n=7,+170%) 운=노이즈**(분기 3+/3−, 일관성 게이트 탈락). 강추박스 n=3 무신호. → 세션서 거짓양성 2건(+230% 누수·+9.6% 노이즈) 일관성/walk-forward로 격파. **ROI 갈래 완전 종결.**

## 선별 베팅 ROI (2026-06-27) — 단·연승 천장 재확인
`npm run probe:picks:roi` (DuckDB 읽기, 38,518행 전부 배당조인). **단·연승 한 마리 베팅으로 강추는 흑자 X:**
- 강추 **연승** 73.1% 적중인데 평균배당 **1.22배** → **ROI −10.9%** (인기마라 적중↑·배당↓ 상쇄).
- 강추 **단승** 41.2%·2.14배 → −11.9%. 베이스 연승 −24%·단승 −28.4%.
- 선별은 "덜 잃게"는 함(베이스 −24%→강추 −10.9%)이나 흑자선(0%) 못 넘음. **베팅 수준에서도 시장 천장 재확인.**
- 분기별 강추 연승 9분기 중 양수 3·음수 6 = 일관성 없음(흑자 신호 아님).
- ⚠️ 미세 신호: 강추×단승 **중배당(4-7배) +15.2%** 이나 n=31 노이즈 경계(backtest:value가 이미 탐색→천장).
- 정직성: 사후 확정배당 → 낙관적 상한. 선별의 가치 = "돈"이 아닌 "적중·출혈최소·의사결정 보조".
