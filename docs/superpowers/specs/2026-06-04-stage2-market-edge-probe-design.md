## 0. 한 줄 요약

베팅 시스템을 짓기 전에, **Stage-1 로지스틱이 시장(win_odds)을 이기는 영역이 존재하는지** 데이터로 찾는다. 핵심 검정: "시장이 같은 가격을 매긴 말들 안에서, 모델 점수가 여전히 승패를 가르나?" 읽기 전용 probe. 엣지가 있으면 Phase 1(value 베팅 레이어), 없으면 재고.

---

## 1. 배경·동기

Stage-1 검증에서 로지스틱은 **v1을 +5.2%p(유의) 이기지만 시장엔 -6%p로 진다.** 결정적으로 [불일치] 분석: 모델 1픽 ≠ 인기1위인 경주(47%)에서 **모델픽 연승 51% vs 인기픽 64%** — 모델이 시장과 엇갈릴 때 오히려 더 틀린다.

value 베팅은 본질적으로 "시장과 엇갈리는 곳"에 거는 것이므로, **모델이 시장을 이기는 영역이 실재하는지 먼저 확인하지 않으면 체계적으로 잃는다.** 그래서 Phase 0 = 엣지 존재·위치 탐색.

전제 발견(Stage-1): 데이터·모델복잡도를 늘려도 연승이 안 올랐다(포화) → 시장을 이기려면 **새 신호가 아니라, 시장이 비효율적인 특정 영역**을 찾아 거기서만 모델 정보를 쓰는 것이 현실적.

---

## 2. 방법론

### 2.1 핵심 검정 — 조건부 엣지 (척추)

win_odds(단승 배당)는 시장의 "이 말 강도" 가격이다. 같은 배당 구간 = 시장이 비슷하게 본 말들.

- 배당 구간으로 묶는다.
- 그 구간 **안에서** 모델 P(top3)로 **터셀(상/중/하 3분할)**.
- 각 터셀의 **실제 top3율** 비교.
- **스프레드 = (상위 터셀 top3율) − (하위 터셀 top3율).** 양수면 = 같은 가격인데 모델 고점수 말이 더 자주 입상 = **시장이 모르는 정보를 모델이 가짐 = 엣지.**

이 검정은 calibration 없이 엣지를 직접 검출하고 베팅에 직결된다(저평가마 = 같은 가격·고모델점수). 모델은 구간 내 **순위**로만 쓰므로 P(top3) vs win_odds 단위 불일치를 우회한다.

### 2.2 시장 보정 베이스라인 (모델 무관)

배당 구간별 **실제 win/top3율 vs 시장 내재확률**(`1/win_odds`를 경주 내 정규화). 장축마 편향(고배당 과대베팅 = 실제 < 내재) 위치 지도. 엣지가 존재할 수 있는 영역의 선험적 표시.

---

## 3. 슬라이스 (각 슬라이스 안에서 2.1 반복)

사전 고정(다중검정 방지). 각 차원에서 배당 구간 × 모델 터셀의 스프레드를 본다.

1. **배당 구간** (주축, 항상): `<2 / 2–4 / 4–7 / 7–15 / 15–30 / 30+`
2. **출전두수**: 소 `≤8` / 중 `9–11` / 다 `≥12`
3. **거리·경마장·주로**: 거리 단(`≤1300`)·중(`1301–1700`)·장(`≥1701`) × meet 서울(1)/부경(3) × 주로 건/습
4. **모델 확신도**: 경주 내 모델 1픽의 2픽 대비 logit 격차를 3분위로 → 확신 큰 구간에서만 엣지 있나

---

## 4. 방법·구현

- Stage-1 로지스틱을 train<2025로 학습(단일 분할; 필요 시 확장윈도우 옵션). `data/training_matrix.jsonl` + `fitLogistic`/`alignFeatures` 재사용.
- 테스트 horse별 산출: 모델 logit·win_odds·ord·field_size·rc_dist·meet·track_type.
  - 행렬에 `race_date`·`meet`·`rc_no`·`ord`·`win_odds`는 이미 있음. **field_size**는 경주별 행 수로 계산.
  - **rc_dist·track_type**은 행렬에 없음 → **재추출 대신 `races` 테이블을 probe가 1회 로드해 `(race_date,meet,rc_no)→{rc_dist,track_type}` 맵으로 조인**(3,619경주, 가벼움). 10분 재추출 회피.
- 읽기 전용 스크립트 `scripts/probe_market_edge.ts`. 행렬 + `races` 조인 1회.

## 5. 출력 & 판정 게이트

### 출력
슬라이스별 표. 예(배당 구간 주축):

```
배당구간 | n   | 모델터셀 top3율 (하/중/상) | 스프레드 | 시장내재 vs 실제
2–4     | ... |  48 / 55 / 63              | +15%p   | ...
4–7     | ... |  28 / 33 / 41              | +13%p   | ...
...
```
각 차원(두수·거리·주로·확신도)마다 동일 표 + **분기별 재집계**(일관성 확인).

### 게이트
- **엣지 있음**: 어떤 슬라이스가 **견고한 양의 스프레드**(다분기 일관 + 표본 충분, 대략 +8%p↑ 지속) → **Phase 1**(그 구간 타깃 value 베팅 레이어: calibration + 베팅타입 배당 + 스테이킹 + 가상 ROI).
- **엣지 없음/약함**: 시장이 우리 모델엔 효율적. → 재고(시장신호 결합으로 적중률만 올리거나, Stage-1만 프로덕션화하고 value 포기).

---

## 6. ⚠️ 정직성 장치 (필수)

- **다중검정**: 슬라이스를 많이 자르면 우연히 양의 스프레드가 나온다. 가설은 §3의 4개로 **사전 고정**, 추가 슬라이스 즉흥 탐색 금지. 판정은 **다분기 일관성 + 표본수(n)** 로만. 단일 분기의 큰 스프레드는 노이즈로 취급.
- **표본 경고**: 터셀×배당구간×슬라이스로 쪼개면 셀 n이 작아진다. n<200 셀은 참고만.
- **범위 한정**: Phase 0은 엣지 **존재·위치만** 확인. calibration·베팅타입 배당·스테이킹·실제 ROI는 Phase 1.
- **look-ahead 없음**: 모델은 train<2025로 학습, 테스트는 2025~. win_odds는 경주 전 값(베팅 가능 시점). 행렬 feature는 이미 as-of.

---

## 7. 범위

- **본 Phase 0**: `probe_market_edge.ts`(행렬 + `races` 조인; 조건부 엣지 + 시장 베이스라인 + 4슬라이스 + 분기 일관성).
- **Phase 1 (별도 spec, 엣지 확인 시)**: 확률 calibration(출전두수 보정), 시장 대비 value 산식, 스테이킹(flat/Kelly), 가상 ROI 백테스트.
- **무관**: B3 프로덕션화(Stage-1 로지스틱 승격)는 이 트랙과 독립 — 병행 또는 후속.
