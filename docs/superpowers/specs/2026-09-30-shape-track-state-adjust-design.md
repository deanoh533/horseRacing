## 1. 배경

전개 피처 `shape_pred_gap`·`shape_p_achieve`(v7-shape 채택)는 말별 과거 기록을 **par 대비 편차**로 바꿔 평균낸다.

- par3 = 경마장×거리 g3f 누적시간 중앙값, par6 = 경마장×거리 종반 600m 중앙값 (`src/engine/shapePar.ts`)
- 말별 `meanD3`·`meanD6` = 과거 최근 기록 편차 평균 (`src/engine/features/shapeSignals.ts` `horseShapeStats`)
- **par에 주로 상태 차원이 없다.**

스파이크(말 고정효과 + 경마장×거리 고정효과 회귀, 날짜×경마장 군집 표준오차) 결과, 젖은 주로는 **더 빠르다**(모래가 다져짐). 구간별로 다르다.

건조 대비 % 변화 (**2024-01-01 미만 데이터만으로 재추정**, 표본 32,551행·말 4,151, trim 1.04):

| 상태 | 초반(출발~결승 600m 전) | 종반(마지막 600m) |
|---|---|---|
| 건조 | 0 (기준) | 0 (기준) |
| 양호 | +0.02% (±0.41) | +0.74% (±0.49) |
| 다습 | −0.27% (±0.35) | +0.48% (±0.61) |
| 포화 | −1.41% (±0.50) | −0.93% (±0.71) |
| 불량 | −2.15% (±0.54) | −1.78% (±0.87) |

(전체 데이터 추정은 초반 다습 −0.55·포화 −1.19·불량 −1.82, 종반 다습 −0.04·포화 −1.02·불량 −1.67. 포화·불량은 표본이 달라도 안정, 다습은 흔들리며 0을 포함한다. 예외로 **종반 양호 +0.74%(±0.49)는 0을 벗어나나** 전체 데이터에서는 +0.28%(경계)로 표본 의존적이라 보정하지 않기로 했다 — §2 확정안.)

**왜 문제인가.** 같은 경주 안에서는 모든 말이 같은 주로라 편차 비교(`predGap`, `pAchieve`)는 상쇄된다. 그러나 **말별 과거 평균**은 말마다 다른 상태의 경주가 섞여, 불량 경주에서 뛴 말은 초반이 ~1.7초 "빨라 보인다". 경주 내 초반 SD가 0.66초이므로 편향이 1.3 SD로 결코 작지 않다. 포화·불량 경주 ≈14%, 다습 ≈18%.

**기대치는 낮게 잡는다.** ⑳ 속도능력지수는 par 버킷이 이미 상태별이라 보정 이득이 ~0이었다(스파이크 검증에서 동률). 전개 피처는 par에 상태가 없으므로 이득 여지가 있으나, 편향이 걸리는 말이 일부라 효과는 작을 것으로 본다. 이 스펙은 "효과 있으면 채택, 없으면 기각"을 사전에 못박는 용도다.

## 2. 보정 방식 (설계)

**주로 상태별 고정 계수로 g3f·fin600을 "건조 환산 시간"으로 바꾼 뒤** par 계산과 말별 편차 계산 **양쪽에 동일하게** 쓴다.

```
adj_g3f    = g3fAcc / (1 + c3[state])         // 초반 계수
adj_fin600 = fin600 / (1 + c6[state])         // 종반 계수
```

- 계수표 `c3`·`c6`는 **2024-01-01 미만 데이터로 한 번 추정해 코드에 고정**(동결). 재학습·재추정은 이번 범위 밖 — 라이브에서 표본이 늘어도 임의로 바꾸지 않는다(재학습 동결정책과 같은 취지).
- par(중앙값)도 환산 시간 기준으로 다시 만든다 → 편차 = 환산시간 − par. 상태 편중(예: 우기 시즌 표본)이 par에 새는 것을 막는다.
- 상태값은 `race_entries.track_type` 라벨(건조·양호·다습·포화·불량). 결측·미지 라벨은 보정 없음(계수 0).
- 영천(meet 4)은 par 버킷에서 기존처럼 meet 3 취급을 유지한다(이번 변경과 무관).

**기각한 대안:** par를 경마장×거리×상태 버킷으로 세분 — 버킷당 표본이 희박(경주 수 ↓)하고 영천 등 신설 버킷은 더 심해진다. 회귀 계수 한 벌을 공유하는 쪽이 안정적이다.

**계수 산정 — 확정(Q1=B):** 포화·불량만 보정한다. 양호·다습은 0.
동결 계수(초안값, 2024 미만 추정): c3 = {포화 −0.0141, 불량 −0.0215}, c6 = {포화 −0.0093, 불량 −0.0178}. 최종값은 구현 시 프로브를 `--until 20240101`로 재실행해 그대로 옮긴다.

검토한 옵션:
- A. 4개 상태 계수를 전부 그대로 사용
- B. 포화·불량만 보정, 양호·다습은 0 (노이즈 보정 방지) — **채택**

## 3. 사전등록 판정

### 3.1 1단계 — 예측력 사전점검 (벤치마크 전, 싼 검증)

질문: 환산하면 "다음 경주의 초반·종반 시간"을 과거 최근 5경주 평균으로 더 잘 맞히는가.

- 대상: 2024-01-01 이후 경주(계수 추정에 안 쓴 구간), 말별 과거 최근 5경주 as-of 평균으로 다음 경주 d3·d6 예측.
- 비교: 무보정 vs 보정(같은 par 방식). 지표: 예측 RMSE.
- **통과선(확정):** 연도별 3개 슬라이스 중 2개 이상에서 초반 또는 종반 RMSE가 **상대 1% 이상** 감소. 미달이면 2단계 없이 종결(기각).

### 3.2 2단계 — 통제 A/B 벤치마크

- 같은 스펙에서 **주로 상태 보정 ON vs OFF** (shape 피처 자체는 양쪽 다 포함). 새 플래그(안): `--shape-state-adjust`.
- 시험 창: 2025Q1~2026Q2 (6분기), 학습은 2022~ (v7-shape와 동일).
- 판정 지표: Logistic(t3) **연승 Δ** (ON − OFF).
- **채택선(확정):** 평균 Δ ≥ **+0.5%p** 이고 6분기 중 **4분기 이상 Δ>0**.
- 참고 진단(판정에는 안 씀): 단승·복승 Δ, `shape_pred_gap`·`shape_p_achieve` 계수 변화, 포화·불량 경주만 따로 본 Δ(보정이 걸리는 부분집합).
- 기각: 채택선 미달. 부호는 양이나 선 미달이면 "보류(유지)"가 아니라 **기각**으로 기록한다(파라미터 튜닝 재시도 금지 — 임의 재시도는 다중비교).

### 3.3 한계 (사전에 인정)

- shape 피처 자체가 이미 v7 학습·검증에 쓰여 **손대지 않은 검증 구간이 없다**. 그래서 통제 A/B(같은 스펙 ON/OFF) 외에는 근거로 삼지 않는다.
- 계수는 2024 이전 추정이라 시험 창에는 누수가 없다. 다만 par는 as-of 컷오프 방식을 그대로 따라야 한다(`shapeParMapAsOf`).
- 효과가 작아 +0.5%p 선은 분기별 노이즈(±1%p대)에 묻힐 수 있다. 그래서 "평균 + 부호 일관성" 두 조건을 같이 건다.

## 5. 테스트

- 환산 함수: 상태별 계수 적용·건조는 항등·미지 상태 항등.
- `horseShapeStats`: 상태 다른 두 기록이 같은 환산 시간으로 수렴하는 케이스, 보정 OFF 시 기존 결과와 비트 단위 동일(회귀 방지).
- `buildShapeParMap`: 환산 후 중앙값, 표본 부족 버킷 기존 규칙 유지.

## 7. 범위 밖

- ⑳ 속도능력지수 상태 보정(스파이크상 이득 ~0, 재제안 안 함).
- 영천 par 대체(계수표로 par 표본 부족을 메우는 용도)는 별도 과제.
- 성향 분류(선행/추입)는 코너 순위 기반이라 상태 무관 — 변경 없음.
- 라이브 승격·v8 재학습은 채택 판정 이후 별도 결정.
