# F-004 H7 교차표 UI (/insights) — 설계 스펙

> 2026-07-18 브레인스토밍 승인. 전개 트랙 스펙(2026-07-08) §7 "범위 밖" 이월 항목의 1단계.
> 범위 결정(사용자): **정적 교차표부터** — 말별 매핑(서버 저장 필요)은 후속. 위치: **새 페이지 /insights**.

---

## 1. 목적

전개 트랙에서 실측으로 검증된 가장 강한 결과 — **예측 격차 × 필요속도 달성확률 12칸 교차표(칸 간 승률 최대 8배 분리, as-of 재현 H9 기준 4.8배)** — 를 사람이 볼 수 있게 노출한다. v7이 이 신호를 피처로 이미 학습에 쓰고 있으므로 모델 기여 목적이 아니라 **관전·복기용 배경 자료**다.

## 2. 수치 생성 — `scripts/export_h7_table.ts` (`npm run export:h7`)

- probe H9의 SQL(`scripts/probe_race_shape.ts` 390~440행: as-of 격차·달성확률 산식, 격차 4구간 × 달성확률 3구간)을 **그대로 복사**해 로컬 DuckDB에서 실행 → `client/src/data/h7_table.json` 출력. probe 파일 자체는 수정하지 않음(진단 도구 불변) — 양쪽에 상호 참조 주석.
- JSON 스키마:
  ```json
  {
    "generatedAt": "2026-07-18",
    "raceDateFrom": 20220101, "raceDateTo": 20260626,
    "totalStarts": 12345,
    "formula": "격차=예측 G3F 시간차(as-of 이력) · 달성확률=필요 종반속도 달성 확률(개체 이력 정규근사)",
    "cells": [
      { "gapBucket": "~0.5초", "achieveBucket": "낮음(~30%)", "starts": 999, "winRate": 0.178, "placeRate": 0.42 }
    ]
  }
  ```
  cells는 12개(격차 `~0.5초`/`~1.0초`/`~1.5초`/`1.5초+` × 달성확률 `낮음(~30%)`/`중간(30~70%)`/`높음(70%+)`).
- JSON은 **커밋해 번들 포함** — 런타임 쿼리 0·egress 0. 갱신은 수동(`export:h7` 재실행 — 재학습 사이클 등). 생성일이 화면에 표시돼 신선도 투명.
- 스크립트는 JSON 저장 전 스키마 검증(12칸 전부 존재·수치 범위)을 자체 수행하고 실패 시 exit 1.

## 3. 화면 — 새 페이지 `/insights` "전개 인사이트"

- 라우트 `/insights` 신설, 진입은 헤더의 Lab("개인 도구")과 같은 방식으로 링크 추가. 모바일 하단 4탭은 변경 없음.
- **교차표**: 행=예측 격차 4구간, 열=달성확률 3구간. 셀에 승률(주 표기)·연승률·표본수(작게). 승률에 따라 셀 배경 강도 차등 — 기존 다크 테마 변수·Tailwind만 사용(차트 라이브러리 없음). 표본 30 미만 칸은 수치를 흐리게 + "표본 적음" 표기.
- **읽는 법(상단 2줄)**: "격차 = 경주 전 예측되는 선두와의 G3F(결승 600m 전) 시간차 / 달성확률 = 그 격차를 뒤집는 데 필요한 종반 속도를 이 말이 과거 이력상 낼 확률".
- **하단 메타**: 표본 기간·경주수·생성일 + 주의문 "이 신호는 v7 모델이 이미 피처(shape_signal)로 학습에 사용 중 — 이 표는 사람용 배경 자료".
- 페이지 구조는 이후 F-005(사후 리뷰)·페이스 실측표가 추가될 수 있게 섹션 단위로.

## 4. 테스트

- export 스크립트의 변환·검증부를 순수함수로 분리해 단위 테스트(루트 vitest): SQL 행 → JSON 셀 매핑, 12칸 검증 실패 케이스.
- 페이지는 타입체크 + 사용자 시각 확인.

## 5. 범위 밖

- **말별 매핑**("이 말은 어느 칸") — 서버가 shape_pred_gap·p_achieve를 predictions에 저장해야 가능(쓰기 경로 변경+마이그레이션). 필요성 확인되면 별도 사이클.
- 교차표 자동 갱신(cron) — 수동 갱신으로 시작.
- H7(사후 실측판) 표 병기 — as-of판(H9)만. 사후판은 F-005에서 재검토.
